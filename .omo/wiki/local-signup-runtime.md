# 로컬 회원가입 확인

확인일: 2026-11-02. 출처: `docs/tasks/NATIVE-AUTH-UI-001.md`의 Runtime follow-up, `backend/scripts/Start-LocalBackend.ps1`, `app/.../MainFragment.java`.

## 사실

- 앱의 "연결을 확인한 뒤 다시 시도해 주세요." 문구는 네트워크 오류일 때 나온다. 이번 회원가입 실패의 원인은 코드가 아니라 꺼진 로컬 서버였다.
- 로컬 서버는 시작한 작업 세션이 끝나면 함께 꺼진다. 회원가입이나 로그인이 연결 오류로 실패하면 8080 포트 리스너부터 확인하고 위 스크립트로 다시 켠다. 에뮬레이터는 tcp:8080 reverse가 필요하다.
- 입력칸 오류 영역은 `setError(null)`만으로 사라지지 않고 간격이 남는다. `setErrorEnabled(false)`로 꺼야 한다.

## 미확인

- 항상 켜 두는 로컬 서버 운영 방식은 정해지지 않았다.

## 새 여행 날짜 선택

확인일: 2026-11-02. 출처: `app/.../trip/TripDateRangeView.java`, `docs/tasks/NATIVE-AUTH-UI-001.md`.

- 사실: Material 날짜 선택 창은 이 앱의 흑백 테마에서 선택 후 배경이 회색으로 칠해지고 선택 구간이 보이지 않았다. 배경과 구간 색을 지정해도 해결되지 않아 화면 안에 넣는 자체 달력으로 바꿨다.
- 미확인: 위 회색 현상의 정확한 원인.

## 에뮬레이터 한글 입력

확인일: 2026-11-02. 출처: Pixel_8 입력칸 직접 확인, AVD 설정 `hw.keyboard=yes`.

- 사실: 입력칸은 한글을 막지 않는다. 키보드 언어가 English(US)면 영문만 입력된다. 왼쪽 떠 있는 도구막대의 `US` 버튼에서 한국어(두벌식)를 고르면 키 입력이 한글로 조합된다.
